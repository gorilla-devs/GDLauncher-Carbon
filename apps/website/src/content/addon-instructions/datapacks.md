## Installing this data pack

Data packs add recipes, loot tables, and gameplay tweaks without needing mods. They work with vanilla Minecraft.

**Through GDLauncher (applies to all worlds):**
Go to the **Addons** tab and click **Add Addons**. Select **Data Packs** from the dropdown on the left of the search bar, paste the Quick Install ID from above, find the data pack, and click **Download**. This installs the pack for all worlds in this instance.

**Per-world installation:**
Right-click your instance in GDLauncher, select **More options** → **Open folder**. Navigate into the `instance` folder, then `saves`, find your world folder, and open the `datapacks` folder inside it. Drop the .zip in there (don't extract it). This applies only to that specific world.

If the world is already running, type `/reload` in chat. You can verify it's working with `/datapack list`.
