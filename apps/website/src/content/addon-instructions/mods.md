## Installing this mod

Open GDLauncher and click on the instance you want to mod. If you don't have one yet, create a new instance with the + button and pick a mod loader (Forge or Fabric, depending on what this mod supports).

Go to the **Addons** tab and click **Add Addons**. Paste the Quick Install ID from above into the search, find the mod, and click **Download**. GDLauncher handles dependencies automatically.

Hit Play and you're done.

## Before you install

Make sure the mod version matches your Minecraft version and that you're using the right mod loader. Forge mods won't work on Fabric and vice versa.
