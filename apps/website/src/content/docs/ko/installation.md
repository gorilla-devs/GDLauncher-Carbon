# 설치

## Windows

Windows에서 GDLauncher를 설치하려면 메인 페이지로 이동하여 "다운로드" 버튼을 누르기만 하면 됩니다.
설치 실행 파일이 다운로드되며, 그대로 실행해 설치할 수 있습니다.

GDLauncher는 현재 Windows 사용자 계정에만 설치됩니다.

## macOS

macOS에서 GDLauncher를 설치하려면 메인 페이지로 이동하여 "다운로드" 버튼을 누르기만 하면 됩니다.
macOS용 설치 파일이 다운로드되며, 그대로 실행해 설치할 수 있습니다.

이 앱은 유니버설 빌드로, Intel 및 Apple Silicon 모두에서 네이티브로 실행됩니다.

## Linux

Linux에서 GDLauncher를 설치하려면 메인 페이지로 이동하여 "다운로드" 버튼을 누르기만 하면 됩니다. 세 가지 형식을 제공합니다:

- **AppImage**: 단일 자체 포함 파일. 실행 권한을 부여한 뒤(`chmod +x ./GDLauncher__*.AppImage`) 그대로 실행하세요. 패키지 매니저 불필요.
- **`.deb`**: Debian / Ubuntu 및 파생 배포판용. `sudo apt install ./GDLauncher__*.deb` 명령이나 파일 관리자로 설치.
- **`.rpm`**: Fedora / openSUSE / RHEL 및 파생 배포판용. `sudo dnf install ./GDLauncher__*.rpm` 명령이나 파일 관리자로 설치.
