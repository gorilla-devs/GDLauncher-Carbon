# Installation

## Windows

Um GDLauncher für Windows zu installieren, gehe einfach auf unsere Startseite und klicke auf „Download".
Du lädst dann die Installationsdatei herunter, die du anschließend ausführen kannst.

GDLauncher wird nur für deinen aktuellen Windows-Benutzer installiert.

## macOS

Um GDLauncher für macOS zu installieren, gehe einfach auf unsere Startseite und klicke auf „Download".
Du lädst dann das macOS-Installationsprogramm herunter, das du anschließend ausführen kannst.

Die App ist universell, das heißt sie läuft nativ sowohl auf Intel als auch auf Apple Silicon.

## Linux

Um GDLauncher für Linux zu installieren, gehe einfach auf unsere Startseite und klicke auf „Download". Wir bieten drei Formate an:

- **AppImage**: eine einzelne, in sich geschlossene Datei. Mach sie ausführbar (`chmod +x ./GDLauncher__*.AppImage`) und starte sie. Kein Paketmanager nötig.
- **`.deb`**: für Debian/Ubuntu und Derivate. Installiere mit `sudo apt install ./GDLauncher__*.deb` oder per Dateimanager.
- **`.rpm`**: für Fedora/openSUSE/RHEL und Derivate. Installiere mit `sudo dnf install ./GDLauncher__*.rpm` oder per Dateimanager.
