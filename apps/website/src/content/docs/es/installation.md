# Instalación

## Windows

Para instalar GDLauncher en Windows, simplemente ve a nuestra página principal y pulsa «Descargar».
Descargarás el ejecutable del instalador, que podrás ejecutar.

GDLauncher se instala únicamente para tu usuario actual de Windows.

## macOS

Para instalar GDLauncher en macOS, simplemente ve a nuestra página principal y pulsa «Descargar».
Descargarás el instalador de macOS, que podrás ejecutar.

La aplicación es universal: funciona de forma nativa tanto en Intel como en Apple Silicon.

## Linux

Para instalar GDLauncher en Linux, simplemente ve a nuestra página principal y pulsa «Descargar». Ofrecemos tres formatos:

- **AppImage**: un único archivo autocontenido. Dale permisos de ejecución (`chmod +x ./GDLauncher__*.AppImage`) y lánzalo. Sin gestor de paquetes.
- **`.deb`**: para Debian/Ubuntu y derivados. Instálalo con `sudo apt install ./GDLauncher__*.deb` o desde el explorador de archivos.
- **`.rpm`**: para Fedora/openSUSE/RHEL y derivados. Instálalo con `sudo dnf install ./GDLauncher__*.rpm` o desde el explorador de archivos.
