# Installation

## Windows

Pour installer GDLauncher sur Windows, il te suffit d'aller sur notre page d'accueil et de cliquer sur « Télécharger ».
Tu obtiendras alors le fichier d'installation que tu pourras exécuter.

GDLauncher est installé uniquement pour ton utilisateur Windows actuel.

## macOS

Pour installer GDLauncher sur macOS, il te suffit d'aller sur notre page d'accueil et de cliquer sur « Télécharger ».
Tu obtiendras alors l'installateur macOS que tu pourras exécuter.

L'application est universelle : elle fonctionne nativement sur les Mac Intel comme sur Apple Silicon.

## Linux

Pour installer GDLauncher sur Linux, il te suffit d'aller sur notre page d'accueil et de cliquer sur « Télécharger ». On propose trois formats :

- **AppImage** : un seul fichier autonome. Rends-le exécutable (`chmod +x ./GDLauncher__*.AppImage`) et lance-le. Pas de gestionnaire de paquets requis.
- **`.deb`** : pour Debian/Ubuntu et dérivés. Installe avec `sudo apt install ./GDLauncher__*.deb` ou depuis ton gestionnaire de fichiers.
- **`.rpm`** : pour Fedora/openSUSE/RHEL et dérivés. Installe avec `sudo dnf install ./GDLauncher__*.rpm` ou depuis ton gestionnaire de fichiers.
