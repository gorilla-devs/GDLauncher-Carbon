# Migration depuis l'ancien GDLauncher

Si tu utilises encore GDLauncher Legacy, la migration vers GDLauncher Carbon est simple. Voici comment procéder.

## Télécharger GDLauncher Carbon

Tu peux télécharger GDLauncher Carbon depuis notre [site officiel](https://gdlauncher.com).

## Installer / remplacer GDLauncher Carbon

Une fois la nouvelle version téléchargée, installe-la en suivant les instructions correspondant à ton système d'exploitation [ici](/docs/installation).
Installer GDLauncher Carbon remplacera l'ancienne version, car les deux partagent le même identifiant d'application. Tu ne perdras aucune ancienne instance : elles sont stockées dans un dossier différent.

## Importer automatiquement tes anciennes instances

Au premier lancement de GDLauncher Carbon et après ta connexion, une fenêtre d'accueil te proposera d'importer tes anciennes instances.

## Importer manuellement tes anciennes instances

Si pour une raison quelconque l'import automatique ne fonctionne pas, signale-nous le problème [ici](https://discord.gdlauncher.com) en priorité.
Tu peux importer tes anciennes instances manuellement comme suit :

- Crée une nouvelle instance dans GDLauncher Carbon avec la même configuration. S'il s'agit d'un modpack, installe exactement la même version. S'il s'agit d'une instance vanille, installe la même version de Minecraft et le même mod loader.
- Ouvre le chemin des données de l'ancien GDLauncher.
- Copie le contenu du dossier d'instance de l'ancien GDLauncher vers le dossier d'instance de GDLauncher Carbon. Voir la page [dépannage](/docs/troubleshooting) pour les détails sur le chemin des données, ou clique simplement avec le bouton droit sur la tuile d'instance puis « Ouvrir le dossier de l'instance ».

## Supprimer les anciennes instances (optionnel)

Une fois l'import terminé, tu peux éventuellement supprimer tes anciennes instances. Cela ne sera pas fait automatiquement.
