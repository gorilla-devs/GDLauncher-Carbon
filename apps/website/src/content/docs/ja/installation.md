# インストール

## Windows

Windows 版 GDLauncher をインストールするには、トップページにアクセスして「ダウンロード」を押してください。
インストーラーの実行ファイルがダウンロードされるので、そのまま実行できます。

GDLauncher は現在の Windows ユーザーのみにインストールされます。

## macOS

macOS 版 GDLauncher をインストールするには、トップページにアクセスして「ダウンロード」を押してください。
macOS 用インストーラーがダウンロードされるので、そのまま実行できます。

このアプリはユニバーサルバイナリで、Intel および Apple Silicon の両方でネイティブに動作します。

## Linux

Linux 版 GDLauncher をインストールするには、トップページにアクセスして「ダウンロード」を押してください。3 つの形式を提供しています:

- **AppImage**: 単体で完結したファイル。実行権限を付与して (`chmod +x ./GDLauncher__*.AppImage`)、そのまま起動できます。パッケージマネージャー不要。
- **`.deb`**: Debian / Ubuntu およびその派生ディストリビューション向け。`sudo apt install ./GDLauncher__*.deb` またはファイルマネージャーからインストール。
- **`.rpm`**: Fedora / openSUSE / RHEL およびその派生ディストリビューション向け。`sudo dnf install ./GDLauncher__*.rpm` またはファイルマネージャーからインストール。
