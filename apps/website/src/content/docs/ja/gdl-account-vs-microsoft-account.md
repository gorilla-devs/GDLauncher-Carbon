# GDL アカウントと Microsoft アカウント

## 2 つのアカウント体系、1 つのランチャー

GDLauncher にはアカウント体系が 2 つあります。**Microsoft** は Minecraft の所有を証明するもので、プレイに必須。**GDL** は GDLauncher 独自の任意アカウントで、GDL バックエンドを使う機能 (インスタンス共有、プロフィール、表示名履歴) のためのもの。

### Microsoft アカウント

Minecraft Java Edition を購入したアカウント。ゲームライセンスを保有しています。Microsoft はこれを起動に要求し、GDLauncher は Microsoft にサインインしてトークンを取得、起動時に Mojang に渡してサーバーに所有を証明します。

プレイには最低 1 つのサインイン済み Microsoft アカウントが必要。なければ Play ボタンは何もしません。

アカウントごとにローカル保存: アクセストークン、リフレッシュトークン、ID トークン、Minecraft ユーザー名と UUID、スキン参照、アクセストークン有効期限。アクセストークンはバックグラウンドでリフレッシュトークンを使って自動更新されるため、通常は気付きません。

可能なこと: Minecraft の起動、サーバー参加、ゲーム所有。

### GDL アカウント

GDLauncher 独自のアカウント体系。任意。GDLauncher 自身が提供する機能 (Microsoft が気にする必要のないもの) のために存在します。

メールアドレスと表示名でサインアップ、安定したフレンドコードが付与されます。そこから他の GDLauncher ユーザーが関わる機能を利用できます。

ローカルに保存されるのはリンクだけ: この GDL アイデンティティが属する Microsoft アカウントと、GDL バックエンドと通信するための JWT。表示名、フレンドコード、メール、プロフィール画像などは GDL バックエンドに置かれ、UI が必要に応じて取得します。

可能なこと:

- **インスタンス共有。** 右クリック → Share でコードを生成、他の GDLauncher ユーザーが貼り付けてインポート。
- **表示名履歴。** 表示名を変更すると変更履歴が追跡されます。プロフィールカードから過去の名前を確認、必要なら削除できます。
- **プロフィール編集。** 表示名、プロフィール画像、メール回復設定、すべて Settings → Accounts の GDL プロフィールカードから。

## いつどちらが必要？

| シナリオ | Microsoft | GDL |
|---|---|---|
| Minecraft 起動だけ | 必須 | 不要 |
| CurseForge/Modrinth から Mod や Modpack を入れる | 必須 | 不要 |
| インスタンスを友達に共有 | 必須 | 必須 |
| 共有コードを受け取る | 必須 | 必須 |
| フレンドシステム利用 | 必須 | 必須 |
| オフライン (既存インスタンス) | キャッシュ認証が短時間有効 | 不要 |

## 管理方法

両方とも **Settings → Accounts** にあります。

GDL Account セクションがページ上部。サインアウト状態だと Sign in / Sign up ボタン。サインイン後は表示名、フレンドコード (コピー可)、回復メール、認証状態を含むプロフィールカード。下部の Danger Zone から削除をスケジュール (7 日間のクールダウン後に実行) できます。

Microsoft Accounts セクションが下に表として表示。列: Active、Username、Type、Status、UUID、Actions。Status はアカウントごとのトークンの状態を示します:

- **ok** (緑チェック): トークン有効、起動可能。
- **expired** (黄色アラート): トークン期限切れ。Actions 列に表示されるリフレッシュアイコンをクリックすると Microsoft サインインフローに戻されます。
- **refreshing** (黄色リフレッシュ): バックグラウンドで更新中。操作不要。
- **invalid** (赤い X): 更新失敗。expired と同じリフレッシュアイコン、クリックすると Microsoft サインインフローへ。

アクティブを切り替えるには、対象行の Active セルをクリック。アクティブな行はダブルチェックアイコンが表示され、他の行はホバー時に薄く表示されます。

## アカウントの削除

唯一の Microsoft アカウントを削除すると GDLauncher から完全にサインアウトされ、ホーム画面に戻ります。

GDL アカウントにリンクされた Microsoft アカウントを削除しようとすると、削除前に本当にリンクを切るか確認するモーダルが表示されます。

GDL アカウントの削除は 7 日遅延。クールダウン中は同じページからキャンセル可能。
