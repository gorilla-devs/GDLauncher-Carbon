# Installazione

## Windows

Per installare GDLauncher su Windows ti basta andare sulla nostra pagina principale e premere su scarica.
Scaricherai così l'eseguibile dell'installer, che potrai eseguire per installarlo.

GDLauncher viene installato solo per il tuo utente Windows.

## MacOS

Per installare GDLauncher su MacOS ti basta andare sulla nostra pagina principale e premere su scarica.
Scaricherai così l'installer per macOS, che potrai eseguire.

L'applicazione è universale, quindi gira nativamente sia su Intel che su Apple Silicon.

## Linux

Per installare GDLauncher su Linux ti basta andare sulla nostra pagina principale e premere su scarica. Distribuiamo tre formati:

- **AppImage**: un singolo file autonomo. Rendilo eseguibile (`chmod +x ./GDLauncher__*.AppImage`) e avvialo. Nessun gestore di pacchetti necessario.
- **`.deb`**: per Debian/Ubuntu e derivate. Installalo con `sudo apt install ./GDLauncher__*.deb` o dal tuo file manager.
- **`.rpm`**: per Fedora/openSUSE/RHEL e derivate. Installalo con `sudo dnf install ./GDLauncher__*.rpm` o dal tuo file manager.
