# Instalação

## Windows

Para instalar o GDLauncher no Windows, basta acessar nossa página inicial e clicar em "Download".
Você baixará o instalador executável, que pode ser executado normalmente.

O GDLauncher é instalado apenas para o seu usuário atual do Windows.

## macOS

Para instalar o GDLauncher no macOS, basta acessar nossa página inicial e clicar em "Download".
Você baixará o instalador para macOS, que pode ser executado normalmente.

O app é universal, ou seja, roda nativamente tanto em Intel quanto em Apple Silicon.

## Linux

Para instalar o GDLauncher no Linux, basta acessar nossa página inicial e clicar em "Download". Oferecemos três formatos:

- **AppImage**: arquivo único autocontido. Dê permissão de execução (`chmod +x ./GDLauncher__*.AppImage`) e rode. Sem gerenciador de pacotes.
- **`.deb`**: para Debian/Ubuntu e derivados. Instale com `sudo apt install ./GDLauncher__*.deb` ou pelo gerenciador de arquivos.
- **`.rpm`**: para Fedora/openSUSE/RHEL e derivados. Instale com `sudo dnf install ./GDLauncher__*.rpm` ou pelo gerenciador de arquivos.
